จัดการสิทธิ์ร้าน · อนุมัติสลิป

เชื่อมกับ Cloudflare Worker (license-worker) — เก็บวันหมดอายุที่เซิร์ฟเวอร์ กันลูกค้าแก้เครื่องตัวเอง
📖 คู่มือการต่อ License (กดเพื่อดู)
ขั้นตอนที่ 1 · เชื่อมต่อครั้งแรก (ทำครั้งเดียว)
1. ใส่ Worker URL (เช่น https://kaidee-license.xxx.workers.dev) และ Admin Token ในหัวข้อ "1 · การเชื่อมต่อ"
2. กด บันทึก & เชื่อม — ระบบจะจำไว้ ครั้งต่อไปไม่ต้องกรอกอีก
ขั้นตอนที่ 2 · อนุมัติคำขอต่ออายุ (สลิปโอน)
1. หัวข้อ "2 · คำขอต่ออายุ" จะแสดงร้านที่ส่งสลิปมา · กด ↻ โหลดคำขอ เพื่อดึงล่าสุด
2. ตรวจสลิป (กด "ดูสลิป") แล้วกด อนุมัติ — วันหมดอายุจะถูกบวกให้อัตโนมัติที่เซิร์ฟเวอร์
※ ถ้ายืนยันจากหน้า "คำขอชำระ" ระบบจะต่อ License ให้ที่นี่อัตโนมัติด้วย (เมื่อเชื่อม Worker แล้ว)
ขั้นตอนที่ 3 · แก้สิทธิ์ร้านด้วยมือ (กรณีพิเศษ)
1. ใส่ Shop ID (เช่น S1234) · กด "ดูสถานะร้านนี้" เพื่อเช็กก่อน
2. ตั้ง แพ็กเกจ / สถานะ / วันหมดอายุ หรือ ต่ออายุ +วัน · จำกัดเครื่อง (maxDevices) · Grace เน็ตหลุด
3. กด บันทึกการแก้ · ปุ่ม "รีเซ็ตเครื่องทั้งหมด" ใช้เมื่อร้านย้าย/เปลี่ยนเครื่องแล้วเต็มโควตา
ไม่มี Worker URL? หน้านี้ยังใช้ไม่ได้จนกว่าจะ deploy license-worker แล้วนำ URL + Admin Token มากรอก · การอนุมัติคำขอชำระในหน้า "คำขอชำระ" ยังทำงานได้ปกติ (ต่ออายุในระบบร้าน) แค่จะไม่ซิงค์ไป License จนกว่าจะเชื่อม

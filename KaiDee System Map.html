โครงไฟล์ & การปล่อยงาน

ทำครบ 4 ขั้นทุกครั้ง ไม่ข้าม

ที่เก็บไฟล์ (3 ที่ ต้องตรงกัน)

  • root — ไฟล์ทำงานจริงที่แก้
  • kaidee-deploy/ — ชุดขึ้น pages.dev (มี sw.js · hagd-pos-vNN)
  • market-deploy/ — ชุดตลาด/ฟิตเนสแยก

แยกขาดจากงาน Potato (potato-deploy/ · pages/ · js/ · data/) — sw คนละตัว ห้ามคัดปนกัน

กฎในโค้ดที่พลาดบ่อย

  • ฟีเจอร์ฟิตเนสใหม่ = เพิ่ม key ใน PERM_PAGES + ROLE_DEFAULTS + ROLE_TABS
  • ห้าม confirm/alert ในแอปมือถือ → ใช้ชีตในแอป
  • แปลงเวลาข้อมูลเก่าต้อง guard เสมอ

ลำดับปล่อยงาน

1
แก้ที่ root → sync ครบ 3 ที่
2
เปลี่ยน ?v= ทุก html + <meta name="build">
3
bump kaidee-deploy/sw.js → hagd-pos-v{N+1}
4
zip ส่ง user → อัปไฟล์ ข้างในโฟลเดอร์ ขึ้น pages.dev branch main

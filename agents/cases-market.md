## เจ้าของตลาด
- [ ] ทะเบียนแผง: เพิ่ม/แก้/ล็อก · ⚠️ ตรวจว่ามีช่อง `st.contractEnd` หรือยัง (ถ้าไม่มี = บั๊กค้างที่ทราบแล้ว)
- [ ] ออกบิลรอบเดือน: ค่าเช่า + น้ำ + ไฟ + GP → ยอดรวมตรง · หน่วยน้ำ-ไฟติดลบต้องกันไว้
- [ ] รับชำระ: กระเป๋า/QR/เงินสด → บิลเปลี่ยนสถานะ + เขียน ledger
- [ ] `SubscribeView`: การ์ดกระเป๋า · จ่ายด้วย wallet (`KDW.charge`) · บัตร disabled · โน้ตกฎหมายแสดงอยู่
- [ ] รายงาน/settlement/VAT เปิดได้ ตัวเลขไม่ NaN
- [ ] ⚠️ ยังไม่มี UI ตอบผู้เช่า (`d.slips`/`d.tickets`/`d.notices`/`d.vreqs`) = งานค้างที่ทราบแล้ว — ยืนยันว่ายังไม่มี ไม่ต้องรายงานเป็นบั๊กใหม่

## ผู้เช่าแผง (`Market Vendor.html`)
- [ ] เลือก/ผูกแผง (`kd_market_vendor_me` · `?stall=`) → หน้าแรกโชว์สถานะแผง + กระเป๋า(VA) + บิลรอบนี้
- [ ] แนบสลิป → เขียน `d.slips` สถานะ `pending` · แนบไฟล์ไม่ใช่รูปต้องกัน · ไม่ใส่จำนวนต้องเตือน
- [ ] แจ้งซ่อม/ร้องเรียน → `d.tickets` + ไทม์ไลน์ + ยกเลิกเรื่องได้ · 4 หมวดครบ
- [ ] ประกาศจากตลาด: ไม่มีประกาศ → empty state · ประกาศหมดอายุ (`until`) ต้องไม่โชว์ · `pin` ขึ้นบนสุด
- [ ] ขอต่อสัญญา/คืนแผง → `d.vreqs` · `st.contractEnd` เหลือ ≤60 วัน ต้องเตือน (ถ้าไม่มีค่า = ไม่เตือนและไม่พัง)
- [ ] ประวัติหน่วยน้ำ-ไฟ: ค่าเฉลี่ย · เตือน spike >140% · แถบเทียบหน่วย · มีบิลเดียวต้องไม่พัง
- [ ] เติมเงิน/จ่ายบิลด้วย QR: ยอดเกินคงเหลือ · จ่ายซ้ำบิลเดิมต้องกัน

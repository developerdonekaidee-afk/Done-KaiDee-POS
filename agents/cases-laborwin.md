# เคสเทส — โมดูล 4: วิน (Labor Win)
ไฟล์: `Labor Win App v2.html` · `laborwin2-win.jsx` · `laborwin2-worker.jsx`
สถานะ: ⬜ ยังไม่เทส

## ทางเข้า
- [ ] `Signup Chooser.html` ปุ่มวิน → เปิดพร้อม `?role=` + ชื่อ/สี/ภาษา ถูกต้อง
- [ ] role `win` (เจ้าของวิน) กับ `worker` (คนขับ/แรงงาน) เห็นแท็บต่างกันจริง

## ฝั่งเจ้าของวิน
- [ ] ทะเบียนคนขับ: เพิ่ม/แก้/ปิดใช้งาน
- [ ] แท็บ 🎫 แพ็กเกจ (`WinPlan`/`WIN_TIERS`): ทดลอง/199/499 · cap 5/15/60 · รายปี ×10 คิดราคาถูก
- [ ] ซื้อแพ็ก → หักจาก `KDW.biz('labor',win.id)` · เขียน `win.plan{tier,cycle,expiry}` · ยอดไม่พอต้องเตือน
- [ ] เกิน cap คนขับ → บล็อกและบอกให้อัปแพ็ก (ไม่ใช่เพิ่มได้เงียบ ๆ)
- [ ] แพ็กหมดอายุ (แก้ `expiry` เป็นวันในอดีต) → ต้องขึ้นสถานะหมดอายุ ไม่พัง
- [ ] แท็บตั้งค่า → `KDReceivePanel` สลับโหมดรับเงินได้

## ฝั่งคนขับ / แรงงาน
- [ ] รับงาน/ปิดงาน → สถานะเปลี่ยน + รายได้สะสมตรง
- [ ] แท็บ 🎁 ดีล: การ์ดขึ้น · impression นับ mod `labor`/`worker` · กด → `Sponsor Shop.html?from=...`
- [ ] ⚠️ `openPool` ยังไม่ต่อ endpoint จริง = งานค้างที่ทราบแล้ว (ยืนยันว่ายังเป็น mock)

## ข้อมูลเก่า / ขอบ
- [ ] วินที่ไม่มี `plan` เลย → ต้องถือเป็นทดลอง/ไม่มีแพ็ก ไม่ error
- [ ] คนขับ 0 คน / งาน 0 รายการ → empty state
- [ ] มือถือ 390: ปุ่มรับงาน ≥44px · ไม่มี scroll แนวนอน

ภาพรวมการเชื่อมต่อ

เว็บนี้คือ “หน้ากรอกข้อมูล” ของแต่ละทีม (MKT/IT/สาขา) — IT นำข้อมูลไปทำต่อที่ระบบหลังบ้าน (Backoffice/CMPOS) · ตอนนี้หลายส่วนทำงานแบบ ไฟล์/ตัวอย่าง ใช้ได้เลยโดยไม่มีค่าใช้จ่าย · ถ้าต้องการ เชื่อมอัตโนมัติ (API) จะมีค่าใช้จ่าย/ข้อจำกัดตามตารางด้านล่าง

ใช้ได้เลย (ฟรี) เชื่อม API (มีค่าใช้จ่าย/ต้องตั้งค่า) ต้องพัฒนาเพิ่ม (Dev + Backend)
CMPOS / Backoffice
โค้ดโปรโมชัน · บัตรสมาชิก · Item Set · ราคา
เชื่อม API
วันนี้ทำได้ระบบออกไฟล์ .xlsx (ProID / ProStatus / ProExpire) + คัดลอก Code Promotion → IT อัปมือที่ Backoffice · ฟรี · ใช้ได้เลย
เชื่อมอัตโนมัติต้องมี API ของ CMPOS/Backoffice (REST/SOAP) → ต่อ API + ยืนยันตัวตน (API Key / OAuth)
ค่าใช้จ่ายค่า Dev เชื่อมต่อ · อาจมีค่า License/สิทธิ์ API ของผู้ให้บริการ POS
ข้อจำกัดขึ้นกับว่า CMPOS เปิด API ให้ไหม — ถ้าไม่เปิด ต้องใช้ไฟล์ต่อ (วิธีปัจจุบันก็เพียงพอ)
อีเมล (Email)
แจ้งเตือนเข้าอีเมลทีม/บุคคล
เชื่อม API
ตัวเลือกSMTP (เมลบริษัท) · Microsoft Graph (sendMail) · Gmail API · บริการส่งเมล (SendGrid / Amazon SES)
ค่าใช้จ่ายSMTP/Graph/Gmail ฟรีในแพ็กเกจองค์กร · SendGrid/SES คิดตามจำนวนเมล
ข้อจำกัดSMTP มีลิมิตส่ง/วัน · ต้องตั้ง SPF / DKIM / DMARC กันเข้า Spam
Team Chat (Teams / Slack)
โพสต์เข้าห้องแชท + @mention
เชื่อม API
ง่ายสุดIncoming Webhook — โพสต์ข้อความเข้าห้องได้ทันที ฟรี
ถ้าต้อง @mention คนต้องใช้ Bot / Graph API (Teams) — Dev เพิ่ม
ข้อจำกัดWebhook โพสต์เข้าห้องได้ แต่ไม่ mention รายคน · เลือกห้องปลายทางได้ใน “ตั้งค่าแจ้งเตือน” อยู่แล้ว
LINE (กลุ่ม/OA)
แจ้งเตือนเข้ากลุ่ม LINE
เชื่อม API
ต้องใช้LINE Official Account + Messaging API (LINE Notify ถูกยกเลิกแล้ว มี.ค. 2025)
ค่าใช้จ่ายมีโควต้าข้อความฟรี/เดือน · เกินคิดเงินตามแพ็กเกจ มีค่าใช้จ่ายเมื่อปริมาณสูง
ข้อจำกัดส่งเข้ากลุ่มต้องเชิญ OA เข้ากลุ่ม + ตั้ง Channel Access Token / Webhook (ตั้งค่าไว้ในหน้า Notification แล้ว)
ปฏิทิน (Outlook / Google)
นัดเตือนวันสำคัญของโปร/โค้ด
ICS ฟรี
วันนี้ทำได้ICS (.ics) โหลด/แนบไฟล์ → เข้าทุกปฏิทิน (Outlook/Google/Apple) ฟรี · ใช้ได้เลย
M365 อัตโนมัติGraph · Calendars.ReadWrite — ฟรีในแพ็กเกจ M365 · ต้อง Admin consent + App registration
Google อัตโนมัติGoogle Calendar API — ฟรีในโควต้า · ต้อง OAuth + Admin อนุมัติ
ข้อจำกัดโหมดอัตโนมัติ เฉพาะอีเมลในองค์กรนั้น (M365/Workspace) — อีเมลส่วนตัวใช้ ICS
Login / SSO
เข้าระบบด้วยอีเมลบริษัท
Dev
วันนี้ตรวจโดเมนอีเมล (ตัวอย่าง) mock
ของจริงSSO กับ Microsoft (Azure AD / Entra) หรือ Google — ฟรีในแพ็กเกจ · ต้อง Dev + Admin ตั้งค่า
ข้อจำกัดต้องมี Identity Provider (IdP) ขององค์กร · กำหนดสิทธิ์ตาม role ได้ (Permissions)
Backend / Database / หลายแบรนด์
ทำให้เป็นระบบจริง รองรับหลายบริษัท
Dev + Backend
วันนี้เก็บข้อมูลในเครื่อง (localStorage) — เหมาะกับ mock/สาธิต mock
ของจริงต้องมี Backend + Database (เช่น Google Apps Script + Sheet, Firebase, หรือ Cloud + SQL)
ค่าใช้จ่ายค่า Hosting + DB ตามขนาดผู้ใช้/ข้อมูล
หลายแบรนด์แยกข้อมูลด้วย Brand Key (วางโครงไว้ในระบบแล้ว) + เปิด/ปิดโมดูลรายแบรนด์
สรุป: เริ่มได้เลย vs ต้องเชื่อม
ใช้ได้เลย (ฟรี)ต้องเชื่อม/พัฒนาเพิ่ม
• ออกไฟล์โค้ด/บัตร ให้ IT อัป Backoffice
• ปฏิทิน ICS (.ics) + Add to Google
• Team Chat ผ่าน Webhook
• คู่มือ/รายงาน/พิมพ์ PDF		 • เชื่อม CMPOS อัตโนมัติ (ถ้ามี API)
• ส่งเมล/LINE/Teams mention จริง
• ปฏิทิน M365/Google อัตโนมัติ
• SSO + Backend/Database จริง

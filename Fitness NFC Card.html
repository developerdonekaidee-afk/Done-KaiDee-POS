ป้าย NFC เช็คอินสำหรับฟิตเนส — ใส่รูปร้าน เว้นช่องแปะสติกเกอร์ NFC · ปริ้นท์/ดาวน์โหลดการ์ด

1 ใส่ข้อมูลฟิตเนส

กรอกชื่อ + อัปโหลดรูป → การ์ดอัปเดตอัตโนมัติ · ช่อง NFC จะเว้นไว้ให้แปะสติกเกอร์จริง · มี QR สำรองให้คนไม่มี NFC สแกนได้
💡 วิธีใช้: เขียนลิงก์เช็คอินลงสติกเกอร์ NFC (ด้วยแอป "NFC Tools") → ปริ้นท์การ์ดนี้ → แปะสติกเกอร์ลงช่องประ (⬡) → ตั้งที่เคาน์เตอร์/ประตู · สมาชิกแตะมือถือเพื่อเช็คอิน

2 การ์ด NFC

ขนาดการ์ดเท่าการ์ด QR พร้อมเพย์ (360px · ~9×15 ซม.)

? คู่มือใช้งาน NFC (สำหรับฟิตเนส)

ทำครั้งเดียวจบ · ใช้ได้ตลอด ไม่มีค่ารายเดือน
1
ซื้อสติกเกอร์ NFC
ชนิด NTAG213 (ค้น "NFC sticker NTAG213" ใน Shopee/Lazada · ~5–20฿/ชิ้น) · ถ้าจะติดบนประตูเหล็ก เลือกรุ่น on-metal / anti-metal ไม่งั้นแตะไม่ติด
2
เขียนลิงก์ลงสติกเกอร์
โหลดแอป "NFC Tools" (ฟรี) → Write → Add record → URL → วางลิงก์เช็คอิน (ปุ่ม "คัดลอกลิงก์เช็คอิน" ด้านล่าง) → แตะมือถือกับสติกเกอร์
3
ปริ้นท์การ์ด + แปะสติกเกอร์
ปริ้นท์/ดาวน์โหลดการ์ดนี้ → แปะสติกเกอร์ NFC ลงในช่องประ (⬡) → ตั้งที่เคาน์เตอร์/ประตู
4
ทดสอบ
iPhone รุ่นใหม่แตะได้เลย · Android เปิด NFC ก่อน · แตะแล้วเด้งหน้าเช็คอิน = ใช้ได้ · ไม่มีสติกเกอร์ก็ให้สมาชิกสแกน QR สำรองบนการ์ดแทนได้
iOS: NFC Tools Android: NFC Tools
⚠️ สติกเกอร์ต้องเป็นชนิดมีชิป (NTAG) เท่านั้น — "แผ่นกันคลื่น/กันโลหะ" ใช้ไม่ได้ · และ NFC นี้ใช้เช็คอินเท่านั้น ไม่ใช่แตะจ่ายเงิน (รับเงินใช้ PromptPay QR)

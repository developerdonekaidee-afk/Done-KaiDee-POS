เทสไล่ตามโมดูล A→J

ทำทีละตาราง ครบทุกข้อในโมดูลก่อนค่อยไปโมดูลถัดไป · ข้อที่ทำตามแล้ว "ผลที่ควรได้" ตรง = ติ๊กผ่าน

จดเฉพาะข้อที่ไม่ผ่าน

เขียนหมายเลขข้อ + สิ่งที่เกิดขึ้นจริง (เช่น "C-04 กดปุ่มแล้วไม่มีอะไรเกิดขึ้น") ในช่องหมายเหตุท้ายโมดูล

แจ้งผมเป็นรายการเดียว

ใช้แบบฟอร์มแจ้งในหน้าสุดท้าย — ส่งมาทีเดียวหลายข้อได้ ผมจะแก้ให้ทีละข้อแล้วบอกว่าแก้อะไรไปบ้าง

✓ ผ่าน (ทำงานถูกต้อง) ✗ ไม่ผ่าน (จดหมายเลขข้อ) เว้นว่าง = ยังไม่ได้เทส / ข้าม

ทุกช่อง ✅ และช่องพิมพ์ในเอกสารนี้ กรอก/ติ๊กได้จริงบนจอ — กรอกเสร็จแล้วสั่งพิมพ์เป็น PDF ค่าที่กรอกจะติดไปในไฟล์

ข้อควรรู้ก่อนเทส: ระบบตอนนี้เก็บข้อมูลไว้ในเครื่อง (client-only / localStorage) — ข้อมูลที่คีย์จะอยู่แค่เครื่องนั้น ยังไม่ sync ข้ามเครื่อง (backend worker/D1 เป็นงานเฟสถัดไป) · เทสทุกอย่างในเครื่องเดียวจบก่อน · ถ้าอยากล้างข้อมูลเริ่มใหม่ ใช้ปุ่มรีเซ็ต/ลบร้านในแอป

02

วิธีแจ้งผมให้แก้ (ส่งทีเดียวเป็นชุด)

คัดลอกแบบฟอร์มนี้ พิมพ์รายการข้อที่ไม่ผ่านส่งมา ผมแก้ให้ทีละข้อ

แจ้งเป็นข้อ ๆ ตามรูปแบบนี้ — ยิ่งบอกละเอียด (หมายเลขข้อ + เกิดอะไรจริง + อยากให้เป็นยังไง) ผมยิ่งแก้ตรงจุด ไม่ต้องเดา:

# แจ้งแก้ UAT รอบที่ ___ วันที่ ___ [C-04] ปัญหา: กดปุ่มทดสอบเสียงแล้วไม่มีเสียง อยากให้: มีเสียงกริ๊งเหมือนที่เขียนไว้ ความสำคัญ: กลาง [E-05] ปัญหา: หักบิลอัตโนมัติแล้วยอดกระเป๋าไม่ลด อยากให้: ยอดลดตามบิลที่หัก ความสำคัญ: สูง (ตัวเลขเงินผิด) [ปรับเพิ่ม] อยากได้ปุ่มค้นหาสมาชิกด้วยชื่อในหน้าขาย (ไม่ใช่บั๊ก — ฟีเจอร์ใหม่)

ระดับความสำคัญ — ช่วยผมจัดลำดับแก้

สูงตัวเลขเงินผิด · กดแล้วพัง · เข้าไม่ได้ · ข้อมูลหาย → แก้ก่อน

  • นับจากเช็คอิน (proxy): คนที่ยัง present ในฟิต × สัดส่วนคัน/คน → จำนวนรถโดยประมาณ (เพิ่ม "เช็คเอาต์ตอนออก" ให้แม่นขึ้น)
  • ปุ่ม ±manual ที่ป้อม/เคาน์เตอร์: รถเข้า +1 / ออก −1 — นับคนนอกที่ไม่ใช่สมาชิกได้
  • แบบสอบถามหลังข้อความต้อนรับ (ฟิตเนสเปิด/ปิดได้): พอแตะบัตร/สแกนเข้า → โชว์ welcome แล้วถามสั้นๆ "ขับรถมาไหม? · ประเภทรถ (เก๋ง/กระบะ/มอไซค์)" → นับรถ + รู้ประเภท · ไม่ถามทะเบียน
  • ต่อเซนเซอร์นับรถ (ถ้ามี): IR/loop ทางเข้า → ป้อนเลขให้แอปโชว์ · แม่นสุด
  • โชว์ในหน้าสมาชิก (จุดขายสำคัญ): การ์ดสถานะลานจอดสดบนหน้าบัตรสมาชิก → เช็คก่อนออกจากบ้าน/ก่อนขับมา · หมดปัญหามาถึงแล้วที่จอดเต็ม + โชว์บนทีวีทางเข้าด้วย

สถานะ: เดโมแนวคิดกดได้จริงแล้ว (Sponsor Shop · Rider) — ยังไม่ปล่อยในแอปจริง · เก็บเงินค่าสินค้า/ค่าส่งวิ่งตรงหาสปอนเซอร์/ไรเดอร์ก่อน (กันเกณฑ์ e-money ธปท.) กระเป๋าแพลตฟอร์มเก็บเฉพาะรายได้เรา

ระบบนิเวศ · ฐานผู้ซื้อรวมทุก vertical

ทุก vertical เห็นร้านสปอนเซอร์เดียวกัน — ฐานผู้ซื้อยิ่งใหญ่ สปอนยิ่งขายได้ ยิ่งต่อแพค

สมาชิกฟิตเนส · ลูกค้าร้าน POS · ร้านค้าในตลาด · แรงงานวิน — คนทุกกลุ่มในทุกธุรกิจ เห็นหน้าร้านสปอนเซอร์ชุดเดียวกัน = ออดิเอนซ์ก้อนใหญ่ที่สุดในที่เดียว สปอนเซอร์ไม่ต้องหาคนซื้อเอง

ยิ่งมีร้าน/ยิม/ตลาดใช้ระบบมาก คนเห็นร้านสปอนยิ่งเยอะ — ออดิเอนซ์ก้อนเดียวที่ใหญ่ขึ้นเรื่อยๆ คุ้มกว่าลงโฆษณาแยกทีละที่

📈

ขายได้ → ต่อแพคยาว

เข้าถึงคนทั้งระบบ = ยอดสปอนต่อเดือนสูง → คุ้มค่าแพค → สปอนต่อรายเดือน/รายปีเอง กลายเป็นรายได้ประจำของแพลตฟอร์ม

🔁

ใครก็เป็นลูกค้า/สปอนได้

ร้าน POS · ฟิตเนส · ซัพพลายเออร์ กดเป็นสปอนเซอร์เอง → ทุกส่วนเป็นทั้งผู้ซื้อและผู้ขาย = โอกาสขายเกิดได้ทุกจุดในระบบ

ยิ่งระบบโต ฐานผู้ซื้อยิ่งใหญ่ → สปอนขายดี → ต่อแพคเยอะ → รายได้แพลตฟอร์มโตตาม = วงจรที่เร่งตัวเอง (flywheel)

รายได้เสริม · แพ็กสปอนเซอร์ (โฆษณา + ขายของ)

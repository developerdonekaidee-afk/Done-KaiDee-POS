ขั้นที่ 1

เตรียมผลงาน + ข้อมูลเจ้าของ

ไฟล์โค้ด/สกรีนช็อตหน้าจอ, ชื่อผลงาน, วันเดือนปีที่สร้าง, ชื่อ-ที่อยู่เจ้าของสิทธิ์ (บุคคล/บริษัท)

ขั้นที่ 2

ยื่นคำขอแจ้งข้อมูลลิขสิทธิ์

ยื่นออนไลน์ผ่านระบบ e-Filing ของกรมทรัพย์สินทางปัญญา (ipthailand.go.th) หรือยื่นที่กรมฯ / พาณิชย์จังหวัด — เลือกประเภทงาน “วรรณกรรม (โปรแกรมคอมพิวเตอร์)” และ/หรือ “ศิลปกรรม”

ขั้นที่ 3

ขั้นที่ 1

ตรวจชื่อ/โลโก้ซ้ำ

ค้นในฐานเครื่องหมายการค้าของกรมฯ ว่ามีคนจด “KaiDee / :D one” หรือคล้ายกันไว้ก่อนหรือยัง

ขั้นที่ 2

เลือกจำพวกสินค้า/บริการ

ซอฟต์แวร์/แอป มักอยู่จำพวก 9 และบริการที่เกี่ยวข้อง (เช่น 35, 42) — เลือกให้ตรงกับที่ใช้จริง

ขั้นที่ 3

ยื่นคำขอ + ชำระค่าธรรมเนียม

ยื่นออนไลน์ (e-Filing) แนบไฟล์โลโก้ → รอตรวจสอบ/ประกาศโฆษณา → รับจดทะเบียน (กระบวนการใช้เวลาหลายเดือน–เป็นปี)

กันคนเลียนแบบ + ตรวจจับการคัดลอก
  • ประกาศลิขสิทธิ์ในตัวงาน — ใส่ © สงวนลิขสิทธิ์ + ชื่อเจ้าของ ในแอปและใน source code
  • Watermark / Canary ในโค้ด — ฝังสตริง/ชื่อคลาสเฉพาะที่ไม่มีใครบังเอิญเขียนเหมือน ถ้าเจอในแอปคนอื่น = ก๊อปตรงๆ (หลักฐานชัด)
  • เก็บโค้ดฝั่ง server ไม่เปิดเผย — คนนอกก๊อปได้แค่หน้าตา ไม่ได้ระบบจริง
  • ค้นแบรนด์เป็นระยะ — Google / App Store / Play / Facebook / ฐานกรมฯ ว่ามีใครใช้ชื่อ-โลโก้คล้าย
  • เก็บหลักฐานการสร้าง — ประวัติการแก้ไขไฟล์/วันที่ ไว้พิสูจน์ว่าเราทำก่อน
สิ่งที่กฎหมายไม่คุ้ม: “ฟีเจอร์/ไอเดีย” (เช่น การจับคู่ยอดเงินเข้า) ใครทำแนวคิดเดียวกันได้ — จุดที่กันได้จริงคือ แบรนด์ (เครื่องหมายการค้า) + โค้ด server ที่เป็นความลับ + ความเร็ว/ฐานลูกค้า
✅ เริ่มจากอะไรก่อนดี: 1) จดเครื่องหมายการค้า “ชื่อ+โลโก้” (กันเลียนแบบแบรนด์ตรงจุดสุด) → 2) จดแจ้งลิขสิทธิ์โค้ด/ดีไซน์ (ฟรี เก็บหลักฐาน) → 3) ปิดโค้ด server + ฝัง watermark

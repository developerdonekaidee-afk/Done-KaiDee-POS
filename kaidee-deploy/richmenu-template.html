เทมเพลต Rich Menu ร้านสำเร็จรูป

ใส่ชื่อร้าน + รหัสร้าน → ดาวน์โหลดรูป Rich menu (2500×1686) แล้วอัปโหลดเข้า LINE OA ของร้านคุณเอง ไม่ต้องออกแบบเอง · ด้านล่างมีตารางบอกว่าปุ่มไหนลิงก์ไปไหน + วิธีตั้งค่าใน LINE OA Manager ทีละขั้น

📌 หน้านี้สำหรับร้านที่ใช้ LINE OA
ใช้ทำ“ปุ่มเมนู”ในแชท LINE ของร้าน (LINE Official Account) — ลูกค้าแอดเพื่อนร้านแล้วกดสั่งได้เลย
ถ้ายังไม่มี LINE OA → ข้ามหน้านี้ได้เลย — ใช้แค่ลิงก์/QR โปสเตอร์วางหน้าร้านก็ขายได้เหมือนกัน

1 ปรับแต่งร้านของคุณ

พิมพ์ชื่อร้าน สโลแกน และรหัสร้าน (shop ID) ที่ได้ตอนสมัคร — รูปด้านล่างจะอัปเดตทันที

2 ตัวอย่าง Rich menu

ขนาดมาตรฐาน LINE แบบใหญ่ 2500×1686 (6 ปุ่ม · 3 คอลัมน์ × 2 แถว) — เส้นประคือขอบเขตปุ่มที่แตะได้ (ตอนดาวน์โหลดเส้นประจะถูกซ่อน)
🍳
ครัวขายดี
สั่งง่าย ส่งไว อร่อยทุกจาน
ไฟล์ที่ได้: 2500×1686 px · PNG · ใช้อัปโหลดใน LINE OA ได้เลย

3 ปุ่มไหน ลิงก์ไปไหน (Mapping)

แต่ละปุ่มตั้ง action เป็น Link (URI) ตามนี้ · พิกัด (X, Y, กว้าง, สูง) อ้างอิงภาพจริง 2500×1686 — ใส่ตรงกับ area ใน LINE ได้เลย
ปุ่มลิงก์ปลายทาง (URI)พิกัดพื้นที่ (px)

4 ตั้งค่าใน LINE OA (ประมาณ 5 นาที)

  1. เข้า LINE Official Account Manager (manager.line.biz) → เลือก OA ของร้าน → เมนู Rich menus → Create
  2. ตั้งชื่อ + ช่วงเวลาแสดง → เลือกเทมเพลตเป็นแบบ “ใหญ่ · 6 ช่อง” (Large, 3×2)
  3. ที่ Background image → Upload รูปที่ดาวน์โหลดจากขั้นตอนที่ 2
  4. แตะแต่ละช่อง แล้วตั้ง Action = Link → วาง URL ตามตาราง “ปุ่มไหนลิงก์ไปไหน” ด้านบน (ช่องติดต่อใช้ tel: หรือลิงก์ LINE ก็ได้)
  5. กด Save → เปิดใช้งาน (Display) → เสร็จ! ลูกค้ากดสั่งได้ทันที 🎉
